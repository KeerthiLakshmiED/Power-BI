# Superstore Sales Analysis Dashboard

## 📊 Project Overview

The **Superstore Sales Analysis Dashboard** is a Power BI project developed to analyze sales, quantity, profit, and discount performance using interactive data visualizations.

## 🎯 Objectives

- Analyze total sales and profit.
- Understand the quantity of products sold.
- Compare sales across different sub-categories.
- Analyze product quantity by region and category.
- Track monthly profit trends.
- Compare yearly profit performance.
- Provide meaningful business insights through an interactive dashboard.

## 🛠️ Tools and Technologies

- Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization

## 📌 Dashboard Features

### 1. Key Performance Indicators

The dashboard displays:

- Total Sales
- Total Quantity
- Total Profit
- Total Discount

### 2. Sales by Sub-Category

A bar chart is used to compare total sales across different product sub-categories.

### 3. Quantity by Region

A donut chart displays the total quantity sold across:

- West
- East
- Central
- South

### 4. Quantity by Category

A donut chart represents quantity based on:

- Office Supplies
- Furniture
- Technology

### 5. Monthly Profit Analysis

A line chart shows the total profit by month and helps identify profit trends throughout the year.

### 6. Yearly Profit Analysis

A horizontal bar chart compares total profit across different years.

### 7. Interactive Filters

The dashboard provides slicers for:

- Sub-Category
- Region

These filters allow users to interactively explore the data.

## 📈 Key Insights

The dashboard helps users identify:

- High-performing sub-categories.
- Regional quantity performance.
- Category-wise product quantity.
- Monthly profit trends.
- Yearly profit performance.
- Business areas that require improvement.

## 🚀 How to Run

1. Open the `.pbix` file using Power BI Desktop.
2. Make sure the dataset is available.
3. Refresh the data if required.
4. Use the Sub-Category and Region slicers.
5. Explore the dashboard charts and KPIs.
